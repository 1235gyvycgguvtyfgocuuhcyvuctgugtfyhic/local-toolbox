# 本地工具箱 (local-toolbox)

> 一个**单文件、离线、纯本地**的中文网页工具合集。下载 `index.html`，双击用浏览器打开即可使用——无需安装任何环境、无需命令行、无任何外部依赖、不上传任何数据。

## ✨ 功能一览

| 功能 | 说明 |
|---|---|
| 📝 **Markdown 即时预览** | 左侧编辑、右侧实时渲染，内容自动保存，刷新不丢失 |
| 📁 **批量文件重命名** | 拖入文件，按规则批量改名，实时预览，三种落地方式 |
| 🔐 **本地密码生成器** | 可调长度/字符类型/数量，安全随机数，一键复制，带强度指示 |

---

## 📝 1. Markdown 即时预览

- 左边写，右边**实时**显示效果
- 支持语法：标题、加粗、斜体、删除线、行内代码、代码块、有序/无序列表、引用、表格、分割线、链接、图片
- 编辑内容**自动保存在浏览器本地**（localStorage），刷新/关闭再打开都不丢

## 📁 2. 批量文件重命名

- 拖入多个文件（或点击选择）
- 支持规则：**前缀、后缀、查找替换、序号（起始值/位数）、保留扩展名**
- 实时预览每个文件的新名字，重名自动标红提醒
- **三种落地方式**：
  - **⬇ 下载改名副本**：直接下载改名后的文件（全浏览器可用）
  - **🪟 导出重命名脚本 (.bat)**：生成一个脚本，放到文件所在文件夹双击即可批量改名（不改动原文件）
  - **📂 选择文件夹直接改名**：浏览器支持时（Chrome/Edge），选一个文件夹直接在电脑上批量改名

## 🔐 3. 本地密码生成器

- 密码长度（6–64）滑块可调
- 字符类型可勾选：大写、小写、数字、符号
- 可一次生成多条
- 可**排除易混淆字符**（0O1lI）
- 基于浏览器安全随机数（`crypto.getRandomValues`），不经过网络
- 一键复制，实时显示密码强度

## 💾 数据与隐私

- **纯前端，无后端、无监控、无追踪、无任何网络请求**
- 所有设置与内容通过浏览器 **localStorage** 自动保存在本机
- **不上传任何数据到任何服务器**

## 🔄 更新方式

本项目是**纯本地工具，没有后端自动更新**。

- 有新版本时，**直接替换 `index.html` 文件即可**
- 旧数据仍保留在浏览器 localStorage 中，**替换文件不会丢失你的内容与设置**
- 发布新版本后，用户重新下载新版 `index.html` 即为更新
